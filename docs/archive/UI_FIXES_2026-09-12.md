# Wirdi UI fixes

Applied to the supplied v16.1.26 source:

1. Landscape overflow hardening
   - Tasbeeh adapts its counter size in landscape and becomes vertically scrollable when needed.
   - Quran view-mode controls use Wrap instead of a fixed Row.
2. Home
   - Added the supplied mosque sunrise artwork as a taller, faded background.
   - Dashboard cards now use a consistent translucent surface treatment so the background reads through them evenly.
3. Prayer
   - Moon display is responsive and can scale up to 3x (450px) without overflowing; the phase name remains beside it.
4. Tasbeeh
   - Added a bead ring around the counter.
   - Bead count follows the selected target (33/100/custom target).
   - Completed beads light up progressively with each tap.
5. Azkar & Duas
   - Extended background artwork into the content area.
   - Reduced dark overlay and made the search field more opaque for readability.
6. Settings
   - Appearance, prayer notifications, and additional reminders are grouped into collapsible sections.
7. Moon & phases
   - Extended background artwork.
   - Increased the main moon size responsively up to 420px and phase thumbnails to 64px.
8. Assets
   - Registered assets/images/generated/ in pubspec.yaml.

Note: Flutter SDK is not installed in this execution environment, so a local `flutter analyze` / build could not be run here. The modified Dart files were checked for balanced delimiters.
